## Description
This project is a Python implementation of the Battleship game, allowing you to play in the following modes:
- AI vs. AI (Level 1 or 2)
- Human vs. AI (Level 1 or 2)

The program handles grid creation, ship placement, shot management, and console-based game display.

### Prerequisites
- The `colorama` library

python3 BN2.py
